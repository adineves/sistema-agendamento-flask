💈 Salão Bot - Sistema de Agendamento
Sistema simples de agendamentos desenvolvido em **Flask** para controle de horários de um salão de cabelereiro/barbearia.
Projeto criado como forma de estudo e prática em backend com Python.


🚀 Funcionalidades
- Criar agendamentos
- Editar agendamentos
- Excluir agendamentos
- Validação de horário duplicado
- Mensagens de feedback (flash)
- Interface simples e responsiva

🛠️ Tecnologias
- Python
- Flask
- SQLite
- HTML
- CSS

⚙️ Instalação e execução
Clone o projeto
git clone https://github.com/adineves/salao-bot.git
cd salao-bot

Crie o ambiente virtual
python -m venv venv

Ative o ambiente
Windows: venv\Scripts\activate
Linux/Mac: source venv/bin/activate

Instale as dependências
pip install -r requirements.txt

Execute a aplicação
python app.py
